這次讓不在 CurseForge 上的整合包可以直接更新，安裝時也看得到進度。

分享者更新整合包後，卡片會顯示「有新版本」，按「更新整合包」就會直接更新你原本的設定檔，不會再多出一個新的設定檔。程式只換掉有變動的檔案，新版本拿掉的模組會移除，存檔、遊戲設定和截圖都不會動。被換掉或移除的檔案會先備份，不滿意可以在「備份與還原」復原。你自己改過、但新版本拿掉的檔案不會被刪掉，完成時會列出來。更新時 CurseForge 不必關閉，只要先關掉這個整合包的遊戲。

安裝整合包時，進度會直接顯示在那張卡片上，不用捲回頁面最上面看。CurseForge 開著的話，按下安裝時就會先告訴你：程式會先下載和核對，最後一步要請你關掉 CurseForge；等到那一步會跳出 Windows 通知提醒你，關掉後就會自動完成。

另外，整合包的版本寫在名稱裡時，卡片不再顯示「整合包版本 未標示」。

注意：在這個版本之前安裝的整包整合包，第一次更新時不會移除新版本拿掉的模組（舊版程式沒有記下當時的檔案清單），有變動的檔案仍會正常更新；之後的更新就會完整處理。
