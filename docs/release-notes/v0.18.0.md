這一版把設定檔、任務檔和自己加裝的模組裡的簡體字改成台灣用語，並讓翻譯資源包確實排在最上層。

- 任務文字直接寫在任務章節檔裡的整合包（例如 The Foll），簡體任務文字會在原檔轉成台灣用語，只改文字，排版、數字和顏色碼不動。
- 設定檔（config、defaultconfigs）和 KubeJS 腳本裡直接寫的簡體字也會轉成台灣用語；設定名稱、註解行和其他語言專用的檔案不會改。整合包留著、遊戲不讀的 quests-backup 不再算進待查。
- 你自己放進 mods 資料夾、不是從 CurseForge 裝的模組，CurseForge 換不回去，所以程式裡寫死的文字現在也會翻譯（簡體轉台灣用語，英文可用 AI 補翻）。CurseForge 自己裝的模組仍不修改。
- OpenLoader 資料夾和模組自動產生的資源包，以前遊戲啟動時會被放到翻譯資源包上面，現在會一起排在翻譯下面。
- 修正任務檔被重複計算兩次、待查數字偏高的問題。
- 修正上一版的表情符號修正對已掃描過的模組沒有生效：這次會重新掃描所有模組，第一次會比平常慢。
- 調整記憶體的步驟改用 CurseForge 中文介面的選項名稱，英文名稱放在括號裡。

舊有設定、報告與備份可繼續沿用。更新後請重新按一次「一鍵完整翻譯並套用」。
