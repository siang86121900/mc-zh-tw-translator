這一版讓開始頁更單純，統一譯名更省事。

介面

- 拿掉「不修改模組檔，集中成翻譯包」選項，翻譯一律直接寫入模組檔，和原本一樣先備份、可還原。
- 「套用後把遊戲語言設為繁體中文」改為預設不勾選，需要時再勾；沒勾選時，套用完成會提醒你在遊戲的「選項 → 語言」切換。

譯名與用詞

- 只列出物品、方塊、生物、效果等「名稱」在不同模組翻得不一樣的情況；按鍵、選單等通用詞在不同情境本來就可能不同，不再列出。
- 英文相同、語系鍵結尾也相同才視為同一個東西，牆上的火把和一般火把這種不同的東西不會被合併。
- 程式會依來源可信度自動推薦譯法（官方譯名、你的譯名、翻譯記憶、既有繁中、參考庫、模組簡中），新增「全部採用建議」一鍵統一。

內嵌函式庫

- 包在其他模組裡的函式庫（例如 ponder、flywheel），直接改寫風險太高。模組包有 KubeJS 時，它們的譯文會自動放到 kubejs/assets；沒有 KubeJS 時會略過並在報告註明。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
