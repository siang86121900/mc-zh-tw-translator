這次修正幾個看得到的問題，並讓整合包卡片多了記憶體建議。

有些模組用自己的字型畫介面，例如 Essential（好友與外觀功能），它的字型裡沒有中文字，翻成中文就會變成一排方框。現在程式掃描時會自動檢查模組自帶的字型，沒有中文字的模組就保留英文，至少看得懂；之前已經寫進去的中文，下次翻譯時會改回英文。報告會在「無需翻譯」寫出原因。因為這次改了掃描方式，下一次翻譯會把每個模組重新掃一次，會比平常慢一些，之後就恢復正常。

整合包主選單的按鈕如果是整合包作者畫好的圖片（例如 Pixelmon 的 singleplayer、quit），圖片上的英文程式沒辦法翻。報告現在會用灰字說明這不是漏翻。

按下開始翻譯或其他工作進行中，左邊選單只能停在正在進行的那一頁，其他頁會變灰，避免在工作中途按到別的東西；工作結束後就恢復。

在 CurseForge 刪掉從「已翻譯整合包」裝的整合包後，卡片會正確變回「安裝」，不會因為資料夾還留著就一直顯示已安裝。

整合包作者沒有寫建議記憶體時（例如從其他啟動器複製來分享的整合包），卡片會依模組數量估一個建議大小，並清楚寫明這是程式估計、不是作者建議，按「怎麼調整記憶體」可以看 CurseForge 的設定步驟。程式仍然不會修改 CurseForge 的設定。
