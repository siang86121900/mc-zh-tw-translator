這一版讓「建立伺服器」也能用在 Fabric 整合包（例如 COBBLEVERSE），並修正 AI 補翻遇到回覆句數不符就整個停掉的問題。之前按建立伺服器只會跳出「這個整合包使用 Fabric／Quilt，目前只能建立 NeoForge 和 Forge 的伺服器」。

一、從 Fabric 官方網站下載伺服器程式，和官方公布的校驗碼相符才使用，再由它從官方下載 Minecraft 伺服器，和 NeoForge／Forge 的做法一樣。

二、模組自己標明只給玩家端用的（例如 Sodium、Iris、小地圖、畫面調整類），試開前就先移到「_已拿掉的模組」資料夾，不刪除。

三、試開時伺服器當掉，程式會看懂 Fabric 的當機紀錄：找出缺少遊戲畫面、聲音元件的玩家端模組，以及需要已拿掉模組才能運作的模組，移出後再試一次。Fabric 的錯誤訊息會依電腦語言寫成中文，程式改讀紀錄裡固定的英文那一行，所以不受語言影響；正常開機也會出現的警告不會被當成當機。

四、run.bat 改用 Fabric 的啟動方式，記憶體一樣在 user_jvm_args.txt 調整。

五、修正 AI 補翻中途停掉的問題：之前 AI 某一批回覆的句數和送出去的不一樣，程式就把整個 AI 補翻停下來，顯示「AI 回傳筆數不符，已停止」，COBBLEVERSE 因此還有兩千多句沒翻（例如主選單的 Start a Server 按鈕、等級上限說明書）。現在對得上的句子照常採用，沒回覆的同一次再送一次，仍沒回覆的下次再送，不會再整個停掉。更新後請對整合包再按一次「一鍵完整翻譯並套用」並勾選 AI，只會補剩下的部分。已經拿在手上的說明書是舊的那本，要重新拿一本才會是中文。

實測：用 COBBLEVERSE 建立伺服器，第一次試開就成功，先拿掉 34 個玩家端模組、留下 104 個；另外把 Sodium、Iris 等 5 個模組的玩家端標示拿掉來考驗，程式從當機紀錄找出並移出了 Sodium 和需要它的 Iris，其餘 3 個在伺服器上沒有問題所以保留。Quilt 整合包目前仍不支援。
