這一版讓一鍵翻譯真正一次到位，現成翻譯也能收到更新。

一鍵翻譯

- 同一個東西在不同模組翻得不一樣時，一鍵翻譯會直接統一成建議的譯名，不用再到「譯名與用詞」頁手動按。
- 模組自帶的繁中如果殘留大陸用語（例如激活、添加、代碼、設置），會改成台灣用語（啟用、新增、程式碼、設定）。
- 官方原版譯名只用在物品、方塊、生物等名稱，避免「Red」這類一般詞蓋掉模組自己的譯名。

翻譯報告

- 「需要校對」改為「建議確認」，只列已套用但值得看一眼的翻譯：AI 補譯、版本不同的參考譯文、自動統一的譯名、改過用語的模組繁中。
- 修正後按「確認這筆」，下次翻譯會自動沿用。

現成翻譯

- 每份翻譯都標示整合包版號，整合包更新後會有對應新版本的翻譯，舊版本的也保留。
- 你安裝過的翻譯有更新時，側欄會顯示「現成翻譯（N 個更新）」，按「安裝翻譯」即可更新。
- 還沒安裝整合包時，會先引導你用 CurseForge 安裝。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
