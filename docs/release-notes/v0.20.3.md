這次修正幾類整合包文字完全沒被翻到的問題，並加上防漏檢查。

CraftTweaker 腳本（整合包 scripts 資料夾裡的 .zs 檔）以前完全沒有掃描，作者在裡面寫的物品提示會一直是簡體中文，例如 Chapter of Yuusha 的靈魂心罐、曲菈緋蘑菇等說明。現在簡體字會在原檔轉成台灣用語，只改那段文字，註解與其他內容不動，一樣先備份、可還原。

TACZ 槍械包（tacz 資料夾）和車萬女僕的自訂模型包（tlm_custom_pack）的語系檔現在會一起翻譯，缺少繁中的槍械包會新增繁中語系檔，槍身上印的簡體品牌字也會轉成繁體。設定檔裡的 .yaml 與舊式 .cfg（例如 Apotheosis 的名字清單）中的簡體字也會轉換。

有些 Patchouli 書本把英文書名和首頁介紹直接寫在書本設定裡（例如 Simply Swords 的 Runic Grimoire），以前因為 CurseForge 會換回模組檔而沒有寫入。現在改用翻譯資源包提供這句英文的中文，模組檔不修改，也不會被 CurseForge 洗掉。

為了避免以後又整類漏掉，掃描結束時會檢查整合包裡每個資料夾，程式還不會讀、卻含有中文或語系檔的檔案，都會在報告列為格式尚未支援，不會當成已經翻完。

仍然無法翻譯的：寫死在 CurseForge 模組程式裡的英文提示（例如 Call of Yucatán 的古代金柱說明），CurseForge 啟動時會把改過的模組換回原版，所以維持英文並在報告寫明原因。
