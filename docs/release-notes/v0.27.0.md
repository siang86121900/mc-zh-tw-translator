這一版把整合包裡所有地名（結構、生態域、維度，也就是指南針和地圖會顯示的名稱）全部重新檢查，並修正一個會影響資源包載入的問題。

一、檔名被轉成繁體（重要）：之前的版本把設定檔裡寫的檔名也當成文字，轉成了繁體。例如 VEFV2.7.1 的 Paxi 載入順序檔，「探险者指南针结构汉化 v3.1.zip」被改成繁體，和實際的檔案對不上，資源包可能沒有照整合包作者設定的順序載入。現在檔名不會再被轉換，之前改掉的會改回原本的檔名。

二、整合包作者附的翻譯包：整合包用 Paxi 載入的「探險者指南針結構漢化」（一千九百多個結構名稱）之前完全沒有被讀到，現在會拿來當參考，只取中文名稱，英文對不上的不用，檔案本身不修改。所以「小汽艇」會改成「飛艇」，AI 翻得比較生硬的名稱也會換成這份翻譯。

三、名稱的檢查：同一個模組裡不同地方被翻成同一個名字的（例如三個生態域都叫「檜木森林」），改用模組自己的簡中；模組繁中和簡中意思差很多的（例如「高嶺土」對「高原旱地」）、名稱留有英文的、生態域叫法和地圖不同的，都列在「建議確認」並交給 AI 核對。AI 新翻的名稱也會再檢查一次，並會拿到地圖上的生態域名稱。另外修正「林地府邸」改為官方的「綠林府邸」、「巖」改為「岩」、「疆盜」改為「強盜」、「西蘭花」改為「青花菜」，以及「終末地」被誤轉成「終終界」的錯字。

更新後請對整合包再按一次「一鍵完整翻譯並套用」，並勾選 AI 補翻與核對。
