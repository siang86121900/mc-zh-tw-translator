這一版在「已翻譯整合包」的卡片上新增「建立伺服器」，按一下就能用你電腦上的整合包做出可以直接開的伺服器。

- 電腦上已經有這個整合包時，卡片會出現「建立伺服器」。選擇或貼上要放伺服器的資料夾（例如桌面上的 Minecraft server），程式會在裡面新開一個「整合包名稱 Server」資料夾，不會動到你原有的伺服器，整合包本身也只讀不改。
- 程式會複製 mods、config、kubejs 等伺服器需要的資料夾，翻好的任務和設定文字一起帶過去；存檔、材質包、光影和遊戲選項不複製。
- 伺服器程式從 NeoForge／Forge 官方網站下載，核對官方校驗碼後才安裝。開伺服器前必須同意 Minecraft 的使用者授權合約（EULA），這一步由你自己按「我同意」。
- 接著自動試開伺服器：只給玩家端用的模組（例如讀取畫面、粒子特效、皮膚載入）會讓伺服器當掉，程式從當機紀錄找出是哪一個，移到「_已拿掉的模組」資料夾（不刪除），再重開，直到開得起來。當機原因不是玩家端模組時（例如 KubeJS 腳本錯誤、模組本身的錯誤），程式不會亂拿東西，會停下來說明是哪個模組。
- 做好後雙擊 run.bat 就能開伺服器。記憶體依模組數量設定上限，以 1 到 10 人、同一台電腦也要開遊戲和其他遊戲來估算，可在 user_jvm_args.txt 修改。拿掉了哪些模組和原因、朋友怎麼連線，都寫在資料夾裡的「伺服器說明.txt」。
- 試開只能確認伺服器開得起來，少數模組要等玩家進遊戲才出錯。目前支援 NeoForge 和 Minecraft 1.17 以上的 Forge，Fabric 還不支援。朋友從外面連線需要自己設定路由器或使用連線工具。
- 修正：附帶語言包裡，模組只是列為「選用前置」但其實沒安裝的文字，以前會被當成已安裝而列入翻譯，現在會正確略過。

這一版第一次翻譯會重新掃描所有模組，會比平常久一些。舊有設定、報告與備份可繼續沿用。
