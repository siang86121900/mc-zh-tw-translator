這一版讓翻譯來源更多、判斷更準，也更好用。

更多翻譯來源

- 新增官方 Minecraft 繁中語系：原版物品、方塊、生物等名稱直接用 Mojang 官方譯名，和遊戲本身一致。會優先讀取本機啟動器已下載的檔案。
- 新增 ParaTranslationPack（釘宮翻譯組），每次翻譯前一樣確認是最新版。
- 新增跨版本 CFPA（1.20、1.19、1.18）：補上同版本參考庫沒收的模組，會標示「跨版本參考」並列入待核對。
- 以 Tensura 為例，缺中文的文字從約 2,650 筆降到約 2,280 筆。

翻譯更準確

- 「無需翻譯」判定更完整：平台與品牌名稱、技術標籤（如 FPS: %s）、座標、按鍵組合、書本樣板變數、指令用法、檔案路徑、色碼、單位（bar、°C、mB）等，不再算成缺漏，也不會送給 AI。只有在所有來源都找不到中文時才會這樣判定。
- 指向未安裝模組的生態域與維度名稱會自動略過。資料包形式的模組（例如 Terralith）也會正確算成已安裝。
- 「待查程式與設定」會自動排除明顯不是顯示文字的程式內部字串（記錄檔訊息、程式碼、識別字），只留下值得檢查的。

新功能

- 套用後把遊戲語言設為繁體中文：很多模組包預設是英文，勾選後會自動改成繁體中文（台灣）。修改前一樣會備份，可以還原。
- 不修改模組檔，集中成翻譯包：有 KubeJS 時放在 kubejs/assets，否則產生一個翻譯模組。更新模組後翻譯不會消失，也能翻到內嵌在其他模組裡的函式庫文字。翻譯模組屬於實驗功能，請進遊戲確認。
- 新增「譯名與用詞」頁：可以固定專有名詞的譯法（例如 Benimaru → 紅丸），AI 補翻時也會照用；並列出同一個英文在不同模組翻得不一樣的詞，一鍵統一。

更快、更穩

- 重新掃描時，沒變動的模組會沿用上次結果。
- 報告檔大約縮小一半，開啟舊報告更快。
- 修正套用時可能讀錯模組檔內容、導致套用失敗的問題。
- 勾選框、下拉選單改成和介面一致的樣式；下拉選單在實際 Windows 桌面上不再出現黑底。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
