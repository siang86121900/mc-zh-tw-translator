## 這一版改了什麼

小幅改善「程式更新」頁，讓你更清楚每一版做了什麼。

### 介面
- **更新說明改成排版後的內容**：標題、條列和粗體會正常顯示，不再出現 `**` 等符號。每個新版本都會附上白話的修正與新功能說明。
- **下載進度只在下載時出現**：平常不再顯示「0%」進度條；下載時會同時顯示百分比。

### 說明文件
- README 改寫成給一般玩家的簡短說明：怎麼用、譯文從哪來、AI 補翻、備份與還原、更新與目前限制。開發與代理作業細節移到 `docs/development.md`。

v0.4.1 的內容（更新後自動重啟、AI 補翻選項、「無需翻譯」分類、報告篩選與每頁筆數等）都包含在這一版。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
