這一版改善「程式更新」頁，讓你更清楚每一版做了什麼。

介面

- 更新說明改成排版後的內容，每個新版本都會附上白話的修正與新功能說明。
- 平常不再顯示「0%」進度條，只在下載時出現，並同時顯示百分比。

說明文件

- README 改寫成給一般玩家的簡短說明：怎麼用、譯文從哪來、AI 補翻、備份與還原、更新與目前限制。開發細節另外放在開發說明文件。

也包含 v0.4.1 的所有改動

- 下載更新後，程式會自己關閉並開啟新版，不再停在「準備重新啟動」。
- 開始頁可以勾選「參考來源缺漏時，用 AI 補翻」；額度不足時自動停用，參考來源照常翻譯。
- 參數（如 %s）、按鍵名稱、羅馬數字、尺寸、NBT 等縮寫標為「無需翻譯」，不算缺漏，也不送給 AI。
- 模組附的繁中語系檔格式損壞時會自動重建；單一檔案出錯不再擋下整包 AI 補翻。
- 翻譯報告改用篩選按鈕、狀態顏色，並可選每頁顯示 50／100／200／500 筆。
- 登入 ChatGPT 後，AI 頁只保留帳號、額度、重新整理與登出。

從 v0.4.0 或更舊版本升級時，畫面可能停在「準備重新啟動」。請手動關閉程式，更新會在 2 分鐘內完成並自動開啟新版。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
