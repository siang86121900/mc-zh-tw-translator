這次讓報告上的紅字「程式還不會讀的檔案」也能自動處理，減少新整合包留下的簡體字。

程式還不認得格式的檔案裡，引號內的簡體字現在會直接在原檔轉成台灣繁體；只有英文或簡中、缺少繁中的語系檔資料夾，會自動補上繁中語系檔。因為還沒確認遊戲一定會讀這些檔案，所以不算進中文化完成率，報告會用灰字說明，也可以從備份與還原復原。存檔、其他語言的檔案、作者名單、模型名稱，以及模組程式裡也有的同一句文字都不會改，避免把模組改壞。

新增支援 FancyMenu 主畫面與暫停畫面的按鈕文字（例如開始遊戲、多人遊戲說明）、KubeJS 的遊戲視窗標題，以及整合包的歡迎說明這類純文字檔，簡體字都會轉成台灣用語。

說明檔（readme、notice）、開發工具檔與模組每次啟動都會重新產生的資料夾不再列成紅字。現在紅字只留下真的轉不了、需要回報的檔案。

另外修正同一個模組在 mods 資料夾裡放了兩個版本時（例如 IMBlocker 5.5.4 和 5.6.2），每次重新翻譯都會輪流改寫同一句的問題。遊戲只會載入較新的版本，現在程式也只採用較新版本的文字。
