這次修正商店文字沒有被翻成繁體中文的問題。

SDMShop 使用的二進位 data 商店檔與 cache 畫面快取現在都會納入掃描，商店分類、商品提示等簡體文字會轉成台灣用語。程式會同時處理商店本體與快取，避免只改其中一份後仍顯示舊文字。

寫入時只替換指定的文字欄位，價格、數量、物品 ID、NBT 型別與其他內容保持原樣。所有受影響檔案仍會先備份，寫入後會重新讀取核對，也能從 APP 還原；再次執行不會重複改寫。

如果其他商店使用尚未支援的文字格式，APP 現在會把檔案列為格式尚未支援，不會默默把它當作翻譯完成。JSON、SNBT、TOML、TXT、KubeJS，以及 SDMShop 的 data 與 cache 格式會照常處理。

另外修正少數可正常啟動的模組檔被誤判為 ZIP 損壞的問題。只有空目錄索引重疊、真正檔案都完整可讀時，APP 會安全重建空目錄並繼續；真正重疊或損壞的檔案內容仍會停止寫入。

模組附帶的簡中語系檔若格式錯誤，現在會略過那一份並用正常的英文、繁中參考庫或 AI 繼續，不再讓整個模組漏掃。OpenLoader 裡沒有玩家文字的配方、詞綴或戰鬥數值 JSON 即使格式錯誤，也不再顯示成翻譯失敗；含玩家文字的錯誤檔案仍會明確列出。
