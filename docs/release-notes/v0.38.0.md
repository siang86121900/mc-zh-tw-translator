安裝整合包時自動帶入封面

新版的兩種整合包安裝流程都會處理封面。CurseForge 官方整合包的翻譯補丁保留原作者封面，玩家自己選的圖片也不會被取代。沒有自訂封面的雲端整合包會依名稱產生有標題與配色的專屬封面，不需要登入 AI 或另外操作。

新打包的雲端整合包會把分享者選用的本機封面一起帶入，原本的雲端下載檔案也能在新安裝時自動產生封面。已有整合包可在更新時補上缺少的封面；需要修改設定時會等待玩家關閉 CurseForge，原設定與圖片先備份，寫入失敗時復原，不動其他整合包或記憶體配置。

自動封面是程式產生的標題與幾何風景設計，並不是每次呼叫 AI 畫圖。已驗證圖片、兩種安裝流程、等待與取消、同名清單核對及失敗復原；實際 CurseForge 的畫面刷新仍需玩家重新開啟確認。此版只更新 APP，不清理雲端舊檔、不重新上架整合包。
