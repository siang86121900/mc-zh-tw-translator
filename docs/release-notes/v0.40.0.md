FTB 任務、Origins 種族與災變模組改成繁體中文

FTB 任務：比較舊的 FTB Quests（1.19.2 與 1.20.1 的部分版本）把任務文字直接寫在任務檔裡，沒有另外的語系檔，舊版只列在報告裡不翻。現在章節名稱、任務名稱、副標題、任務說明與獎勵名稱會照一般順序找翻譯、AI 補翻，翻好後直接寫回任務檔。顏色碼、圖片、換頁標記與任務進度都不動，寫入前會備份，可在「備份與還原」整批還原。

Origins 種族選擇畫面：種族名稱、介紹、種族類別（例如 Divine Blessing）與每個能力的名稱和說明現在會翻成中文。整合包用 Paxi 載入的資料包（例如 Cisco's Rpg Origins）以前完全沒有被掃描，現在會掃描與寫入。

災變模組（L_Ender's Cataclysm）全是英文：這個模組在 1.19.2 版自帶的繁中語系檔少了一個引號，遊戲讀到壞檔就把整個模組的中文（包括本程式的翻譯）一起丟掉。現在遇到模組自帶壞掉的語系檔時，翻譯會另外放一份遊戲讀得到的位置。其他模組以後出現同樣問題也會自動處理。

修正：v0.39.0 修好的 More Sniffer Flowers 在重跑時仍然沒翻，原因是程式沿用了舊的掃描結果；這次會重新掃描所有模組，第一次執行會比平常久一點。

更新後請對 Cisco's Fantasy Medieval RPG、Craft to Exile 2 等整合包重新按一次「一鍵完整翻譯並套用」，任務與種族文字會送 AI 補翻（會使用你的 Codex 額度）。

仍然限制：寫在 CurseForge 管理的模組程式裡的文字（Cisco 盔甲的說明、AllTheLeaks 的記憶體警告、料理效果時間）啟動時會被 CurseForge 換回原版；1.19.2 版神化（Apotheosis）手冊的內容直接從模組檔讀取，資源包無法覆蓋，目前都無法翻譯。
