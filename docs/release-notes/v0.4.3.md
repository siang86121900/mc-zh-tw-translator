這一版讓翻譯結果更準確，介面也更好用。

翻譯更準確

- 模組包附帶的整份翻譯包（例如放在 OpenLoader 的 CFPA 簡中包）裡，沒安裝的模組會自動略過。遊戲根本不會顯示那些文字，以前卻被算成譯文或缺漏；以 Tensura 為例，約 8.8 萬筆因此不再列入。
- 連 jar 裡內嵌的函式庫模組（例如 manascore、ponder）也會算成已安裝，不會被誤略過。
- 來源順序依規則補齊：正確的既有繁中 → 同檔簡中 → 模組包與參考庫 → 你確認過的翻譯記憶 → 術語表 → AI。
- 新增翻譯記憶：在報告裡按「確認這筆」校對過的譯文會被記住，之後翻其他模組包時優先沿用。
- 既有繁中若含簡體字，不再直接採用，會先找更好的來源。
- 模組包 resourcepacks 裡已安裝的繁中翻譯包，也會當成參考來源，減少 AI 用量。
- 「無需翻譯」判定更聰明：開發者註解、唱片的作者與曲名、畫作作者、字型預覽句、數值單位（如 %d FE、%s/t）等不會算成缺漏，也不會送給 AI。
- AI 補翻時，某一筆譯文破壞了參數或數值，只退回那一筆，同批其他譯文照常保留。

介面

- 模組包可以直接從下拉清單選擇：會自動列出 CurseForge、Modrinth、Prism、MultiMC、ATLauncher 的模組包，以及你用過的資料夾。找不到時一樣可以貼上路徑。
- 翻譯紀錄改成看得懂的名稱，例如「Tensura Neo Otherworld · 9/29 01:39 · 未套用 · 12,345 筆」。
- 開始頁更精簡：還沒開始時只顯示一行提示，執行時才展開進度與即時紀錄。
- 翻譯完成時會跳出 Windows 通知，工作列圖示也會顯示進度，切去做別的事也知道何時完成。
- 翻譯報告的原文下方會用小字標出所屬模組。
- 備份頁改成卡片，顯示時間、修改與新增的檔案數，以及可還原／已還原狀態。
- 記住視窗大小；右上角改成小巧的亮色／深色切換鈕。
- 下拉選單改成一般的往下展開，不再出現黑色粗邊。
- 開啟程式時，開始頁不再顯示上一批的數字。

修正

- 修正報告與背景工作同時讀寫時，可能因檔案被佔用而中斷翻譯的問題。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
