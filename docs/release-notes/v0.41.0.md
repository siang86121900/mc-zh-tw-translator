新增：上架的整合包會檢查有沒有清理掉落物的功能，沒有就加裝 Sweeper Maid；修正：建立伺服器時認出藏在別的模組裡的玩家端程式

上架的整合包加裝 Sweeper Maid：翻譯者上架整合包前，程式會先看整合包有沒有自己的清理功能，包括清理模組、清理設定，或會清掉落物的腳本與指令。都沒有時，才加裝 Sweeper Maid 1.1.2，只支援 Minecraft 1.20.1 Forge。它每 10 分鐘把地上的掉落物收進垃圾桶，清掃前會在聊天室提醒，輸入 /sweepermaid dustbin 可以打開垃圾桶把東西找回來。它的提醒原本是英文，程式會一起寫好繁體中文的設定檔。平常的一鍵翻譯不會裝它。

安裝翻譯補丁的玩家：如果翻譯者的整合包有加裝它，卡片會把它列在「翻譯者另外加裝的模組」裡。按下安裝的確認後，程式從 CurseForge 下載同一個檔案，並寫入同一份繁中設定；之後可在「備份與還原」移除。

建立伺服器：有些只給玩家端用的模組會把程式塞進別的模組，例如 Shoulder Surfing 塞進 Create。這時當機紀錄只寫 Create 載入失敗，程式以前因此停下來，不敢拿掉任何東西。現在會從伺服器的紀錄找出真正塞程式的那個模組，把它移到「_已拿掉的模組」，Create 保留，然後再試開一次。The Fool 0.3.2 就是這種情況，拿掉 Shoulder Surfing 後伺服器已經能正常開啟。

更新後不需要重新翻譯。之前建立伺服器失敗的整合包，可以重新按一次「建立伺服器」。
