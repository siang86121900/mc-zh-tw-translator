從 CurseForge 官方版安裝的整合包，現在可以直接用雲端整包的卡片更新，不用重新安裝。像 Society Sunlit Valley 這種官方版已經裝不起來、改成雲端整包分享的整合包，以前用翻譯補丁裝好的玩家，要另外再裝一份才拿得到新翻譯；現在雲端整包卡片會認出你原本那一份，按「更新整合包」就在原本的資料夾換上最新翻譯，存檔、遊戲設定都保留。

更新前會先逐一核對你的每個模組都和卡片上的整合包相同，有任何一個不同就不動任何檔案，並告訴你是哪些模組不同。換掉的檔案會先備份，可在「備份與還原」復原。更新後這個整合包的翻譯都由雲端整包卡片負責，舊的翻譯補丁卡片不會再對它重複安裝。

另外修正雲端整包打包時，把 Bobby 模組記下的伺服器地圖快取也一起分享出去的問題，之後上架的整包不再包含這類個人快取。
