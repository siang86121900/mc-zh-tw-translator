之後上架的整合包會加裝取放紀錄模組 Vonix Guardian，伺服器管理員可以查出是誰、在什麼時間、拿走或放進什麼東西、拿了幾個，也能把被破壞的方塊和箱子還原。玩家端不用裝，只要伺服器有就能用。

一般箱子會記到是哪一個箱子；從 RS、AE2 終端、無線終端或抽屜拿東西時，會記到那位玩家的背包增加了什麼、幾個、在什麼時間，要對時間判斷是誰拿的。查詢結果、說明和還原訊息都改成繁體中文，時間是世界標準時間，台灣時間要再加 8 小時。

安裝翻譯補丁或雲端整包時，同意加裝模組後，程式會從 CurseForge 下載官方檔案並在你的電腦上做繁中處理，可在「備份與還原」移除。分享整合包時不會把紀錄資料庫一起分享出去。
