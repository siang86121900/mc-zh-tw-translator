這一版修正翻譯報告「需要留意」裡的誤報，讓紅字只留下真的還沒翻到、玩家看得到的文字。

一、Elemental Awakening 原本顯示「有 679 個檔案可能含有玩家看得到的文字」，其中大部分不是要翻的文字：冰與火圖鑑的日文、西班牙文等其他語言頁面，設定檔的英文設定值，法術動作的說明，程式代碼與玩家頭顱的皮膚資料，建築告示牌上單一個字母的裝飾等。現在這些不再列出，同一個整合包只剩 13 個真的需要留意的檔案。

二、有些檔案在模組裡原本就是壞的（例如 Dungeon Now Loading 的幾個建築檔解不開），遊戲讀它們也會失敗，不是漏翻。現在改成灰字說明，不再寫「讀取時發生沒有預料到的問題」。

三、「文字涵蓋檢查未完成」不再列出模組裡內嵌的程式庫、音效清單與沒有被使用的檔案。

這一版只改報告的判斷，不會改動已經翻好的文字。更新後重新按一次「一鍵完整翻譯並套用」，報告就會是新的結果。
