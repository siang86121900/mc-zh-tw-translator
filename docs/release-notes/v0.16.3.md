這一版修正開始頁的「還缺中文」和報告頁分類數字對不起來的問題，並讓完成率算得更準。

- 開始頁的大數字和報告頁的分類按鈕改用同一套判斷。「還缺中文」的句數，就是「缺少中文來源」「無法寫入（遊戲中是英文）」「寫入後遊戲讀不到」三個分類，加上已翻好、還沒寫入的句數，不會再湊不起來。
- 模組 data 資料夾裡給伺服器用的英文語系檔不再算成缺少中文。遊戲只讀那裡的英文，畫面上的同一句已在一般語系檔翻好。
- 兩個模組帶了同一個書頁檔時，遊戲只顯示其中一份；只要那份是中文就算完成，不再被算成寫入後讀不到。
- 數字檢查會把英文月份當成數字，December 翻成 12 月不再被誤判為改動了數字。先前因此被退回的 AI 譯文，打開報告時會自動改用，再套用一次即可。

舊有設定、報告與備份可繼續沿用。建議重新按一次「一鍵完整翻譯並套用」，讓報告用新的方式計算。
