這一版把遊戲裡的 Minecraft 名稱統一成台灣官方的叫法。

- 之前簡體中文轉成繁體時只換了字形，所以會出現大陸版的 Minecraft 名稱，例如「下界」「末影人」「生物群系」「惡魂」「潛影盒」「刷怪蛋」「下界合金」。現在會依 Mojang 官方台灣繁中改成「地獄」「終界使者」「生態域」「地獄幽靈」「界伏盒」「生怪蛋」「獄髓」。
- 模組作者自己的繁中、參考庫、AI 補譯和設定說明也一樣會改，改過的句子會列在「建議確認」的「改成台灣用語」，你自己確認過的譯文不會被動到。
- 只換 Minecraft 專有的名稱。像「力量」「橡木」這種一般詞不會換；「監守者」「守衛者」只有整句就是這個名稱時才換，所以模組自己的「地牢監守者」不會被改；數學上的「上下界」也不會被改成「上地獄」。
- 舊版已經寫進遊戲的這類名稱，下次執行時會修正一次，之後重跑不會再變動。
