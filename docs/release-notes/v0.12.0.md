這次新增 CurseForge 整合包的遊戲內設定說明翻譯支援。

能確認語系鍵的模組設定說明，現在會放進翻譯資源包，讓支援的 NeoForge 設定畫面或 Configured 讀取繁中，不必修改原模組。多行說明會等每一行都翻好才一起寫入；重新翻譯時會辨識已套用的內容，保留原本的翻譯來源。

這項支援只影響遊戲內設定畫面，設定檔裡的英文註解不會改動。無法確認語系鍵或畫面不讀語系檔的內容仍會列出原因，不會宣稱已翻好。選用 AI 仍須同意，並沿用既有額度保護。既有備份、報告與設定可繼續使用。

不同設定共用同一語系鍵時，會檢查原文與譯文是否一致；有衝突就列出原因，不互相覆蓋。已有語系條目的說明沿用語系檔翻譯流程，避免重跑反覆改寫。
