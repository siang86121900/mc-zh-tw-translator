這一版修正「已翻譯整合包」頁從零安裝整合包時卡住的問題，讓還沒有整合包的玩家按一個按鈕就能裝好整合包和翻譯。

- CurseForge 裝好整合包後，有時要過一陣子才會把它寫進自己的整合包清單，之前本程式因此一直停在「等待 CurseForge 安裝整合包（0%）」。現在會直接看整合包資料夾裡的紀錄，CurseForge 一裝好就會接著下載翻譯、加入模組並把語言設成繁體中文。從來沒裝過 CurseForge 整合包的電腦也找得到。
- 打開「已翻譯整合包」頁時會重新比對電腦上的整合包。整合包被刪掉後再按「安裝翻譯」，會直接改由 CurseForge 安裝整合包與翻譯，不再只說找不到。
- 翻譯者另外加裝的模組（例如解決輸入法問題的 IMBlocker）改成安裝時一起加入，確認畫面會列出名稱，不用另外選擇。模組一樣只從 CurseForge 官方檔案伺服器下載並核對檔案，之後可在「備份與還原」移除。

舊有設定、報告與備份可繼續沿用。
