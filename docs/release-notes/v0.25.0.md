這一版補上一整類之前漏掉的任務文字。

元素覺醒（Elemental Awakening）等整合包用 Whispering Quests 任務模組，任務放在整合包作者自己做的模組檔裡，而且這個模組直接顯示任務檔裡寫的字，不查語系檔，所以之前的翻譯蓋不到，任務畫面仍是簡體字（例如「寻找伊蕾娜」）。

現在程式會把這些任務的標題、說明、目標、獎勵名稱與章節名稱轉成台灣用語，另外做一個翻譯資料包放在 config\openloader\data 資料夾裡，由 OpenLoader 讓每個世界都讀到，已經開過的世界也一樣。模組檔本身不修改，CurseForge 不會把翻譯洗掉；任務進度不受影響；模組更新時會用新的任務檔重新製作。整合包沒有 OpenLoader 時不會寫入，報告會寫明原因。可以在「備份與還原」整批還原。

另外，模組檔裡還有其他程式還不會讀、卻含中文顯示文字的資料檔時，報告上方會用紅字列出，避免整類文字再被漏掉。

更新後請對整合包再按一次「一鍵完整翻譯並套用」。翻譯資料包含有任務檔的完整複本，所以不會放進分享用的翻譯補丁。
