這次「已翻譯整合包」可以直接安裝不在 CurseForge 上的整合包了。

有些整合包是從其他啟動器搬過來的，CurseForge 上找不到，以前只能分享翻譯，別人沒有同一份整合包就裝不了。現在這類整合包會整包放在分享者的雲端，卡片上會寫「這個整合包不在 CurseForge 上」。你只要按一次「安裝」並確認，程式就會：

1. 從分享者的 Google 雲端下載整合包（已含繁體中文翻譯）。
2. 從 CurseForge 官方下載其餘的模組。
3. 逐一核對每個檔案都和分享者的相同，有任何不同就不安裝。
4. 在 CurseForge 建立一個新的設定檔，不會動到你其他的整合包和存檔。

最後一步需要 CurseForge 是關閉的，程式會提醒你關掉，關掉後自動繼續。裝好後打開 CurseForge，在「我的建立」找到它就能玩，遊戲語言已設為繁體中文。記憶體請照卡片上的建議在 CurseForge 自己調整。

下載中斷時，再按一次「安裝」會從中斷的地方接著下載。Google 雲端在短時間內被很多人下載時會暫停一陣子，這時請晚點再試。

分享的整合包不含分享者的存檔、地圖紀錄、帳號、伺服器清單和個人遊戲設定。不想要時，在 CurseForge 對它按右鍵刪除即可。
