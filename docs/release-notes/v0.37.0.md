雲端整包安裝時自動分配遊戲記憶體

新版會讀取玩家電腦的總記憶體與當下可用量，在新建 CurseForge 設定檔時自動分配遊戲記憶體。優先採用整合包作者建議；沒有提供時依模組數估計，畫面會說明是程式估計。

電腦記憶體不足時會調低，仍能安裝並嘗試啟動，不會因低於建議就禁止安裝。會替 Windows 與其他程式留空間，完成畫面列出實際分配值；低於建議可能較卡或啟動失敗，不保證調低後一定能玩。極低可用量時設定最低 512 MB，提醒先關閉其他程式。

只套用於雲端整包的新安裝，不會覆蓋其他整合包的設定；更新整合包與安裝翻譯補丁仍保留玩家自己調整的記憶體。無法讀取記憶體時沿用 CurseForge 設定並告知，可用「怎麼調整記憶體」手動修改。

已測試記憶體充足、低於建議、其他程式佔用、讀取失敗，以及更新不覆蓋設定。沒有在朋友電腦實測遊戲啟動。本次只更新 APP，未更動整合包上架內容。
