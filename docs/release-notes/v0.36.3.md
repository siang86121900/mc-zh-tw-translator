修正已有 CurseForge 整合包卻仍無法安裝雲端整包

v0.36.2 仍要求讀到總清單或獨立版的 Minecraft 設定。有玩家已在預設位置玩過 COBBLEVERSE，卻因這兩項資料都沒被找到而被擋住。現在會直接檢查預設 Instances 裡的既有整合包設定檔，核對路徑、GUID、遊戲版本、載入器及模組清單後，使用這個位置安裝新的雲端整包。

此修復適用所有雲端整包，不只 Elemental Awakening。不建立空總清單、不修改原有整合包；檔案下載與校驗完成後只建立新整合包的設定檔，重新開啟 CurseForge 後由它匯入。下載期間位置證據消失時，會停止並移除本次新建內容。

已測試只有既有整合包、沒有總清單及獨立版設定的情境，以及錯誤路徑、無效設定檔與失敗復原。未在回報問題的玩家電腦實測。此版本沒有直接呼叫 CurseForge 的私有建立 API；官方 ZIP 匯入的自動呼叫尚未驗證。

本次只更新 APP，不重新上架或更動整合包翻譯內容。
