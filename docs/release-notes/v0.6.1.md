這一版讓翻譯更準、出狀況時更不容易卡住，也更省硬碟空間。

翻譯更準確

- 簡體轉繁體的字形和官方繁體中文一致：不再出現「工作臺」「母巖」，改為「工作台」「母岩」。
- 修正轉換時選錯字：松木不再變成「鬆木」、「最多只能」不再變成「最多隻能」、按鍵「綁定」不再變成「繫結」。
- 含有台、岩、床、群、峰的正常繁體中文，不會再被誤判成簡體而被換掉。
- 新增數值檢查：譯文的數字和英文原文不同時（例如原文 20、譯文 10），會先改用數字正確的來源；找不到才採用，並列在「建議確認」。
- 內建名詞表有 27 個詞改成官方譯名，例如終界使者、鵝卵石、烽火台。
- 「支持者」「質量」這類在台灣也正確的詞，不會再被改成「支援者」「品質」。
- 重新翻譯同一個整合包時，已經套用過的文字不會再被改寫。

比較不會卡住

- 以前 GitHub 查詢次數用完時整個翻譯會停住，現在改用沒有次數限制的方式確認參考庫，檢查更新也一樣。
- 網路不穩時會自動重試，最多 3 次。
- Prism、MultiMC、Modrinth、ATLauncher 的整合包現在可以翻譯了。
- 錯誤訊息改成白話，會說明發生什麼事、下一步怎麼做。

出狀況也救得回來

- 套用或還原途中當機、斷電，現在可以在「備份與還原」把那一批還原；開啟程式時也會提醒。
- 寫入前先檢查硬碟空間，不夠就不會開始寫。
- 選錯資料夾會自動修正或說明：選到 mods 會改用整合包本身，選到外層資料夾會請你選其中一個。
- 確認視窗會寫出要寫入的整合包名稱和路徑。
- 還原舊的一批被擋住時，會說明要先還原哪一批。

省空間

- 每次翻譯的報告從數百 MB 降到約 80 MB。
- 自動清掉舊的更新下載檔和舊版程式，只保留最近一個舊版。舊版留下的報告不會自動刪除。

AI 補翻

- 「AI 帳號與模型」會標出建議的模型並說明原因；沒有自己選過時預設用建議的。
- 模型的官方說明改為繁體中文，滑鼠移上去可看原文。
- 升級後第一次會改用建議的模型；之前自己選過的話，請再選一次。

安全

- 下載的整合包翻譯只能寫入繁體中文語系檔和書本，不能修改英文檔、配方、設定或腳本。
- 下載的翻譯解開前會先檢查大小。

其他

- 「現成翻譯」頁改名為「已翻譯整合包」，功能不變。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
