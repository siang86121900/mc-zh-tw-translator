這一版修正 COBBLEVERSE 實測時看到的英文，以及翻譯資源包沒有被啟用的問題，並讓同一類文字以後都會被找到。

一、翻譯資源包被拿掉（重要）：有些整合包裝了 Default Options 模組，整合包裝好後第一次開遊戲時，它會把資源包清單換成整合包作者預設的那份，翻譯資源包就被拿掉了，遊戲裡大多是英文。現在套用時會把翻譯資源包也加進那份預設清單的最後面，第一次開遊戲就會啟用。修改前一樣會備份，可以在「備份與還原」復原。

二、寫在模組程式裡的物品說明：有些模組把說明文字先交給程式裡的另一個地方保存，之後才顯示（例如 Cobblemon Battle Positions 的「Where opponent's Pokemon spawns」「Required」「Optional」）。之前程式無法確定這些文字的用途，所以沒有翻譯，有些甚至沒列在報告上。現在程式會跟著文字走一遍，確認它只拿來顯示才翻譯；拿去比對、查表或其他模組可能改動的，仍然不改。

三、模組自己漏寫的名稱：有些模組的名稱寫錯地方或沒寫，連英文版都只顯示代碼（例如 block.cobblemon-additions.pokemon_spawner），或把整句英文當成代碼去查（例如「Spawner: %1$s」）。現在程式會在翻譯資源包補上遊戲實際要找的名稱，模組檔不修改。原文用了遊戲看不懂的數值格式（例如 %2$i，英文版也會原樣顯示）時，譯文改用遊戲看得懂的格式，讓數值正常顯示，並列在「建議確認」。

四、伺服器端翻譯的模組：Lenient Death 這類模組把文字放在模組的資料夾裡，由內嵌的伺服器翻譯套件讀取，之前程式寫不進去，遊戲裡一直是英文。現在這些文字也會翻成繁體中文，放進翻譯資源包，遊戲會優先使用，模組檔不修改。

更新後請對整合包再按一次「一鍵完整翻譯並套用」，並勾選 AI 補翻。
