這一版修正探險家指南針（和它在 Xaero 地圖加的路標）裡的結構名稱，讓它們和地圖顯示的名稱一致。

一、原版的結構與分組：原版遊戲本身沒有結構名稱，之前程式也跳過了，所以「Villages」「Pillager Outposts」，以及其他模組加在原版底下的「Pillager Outpost Dark Forest」都顯示英文。現在會補上這些名稱；有官方繁中叫法的直接用官方名稱（例如村莊、針葉林村莊、綠林府邸、海底遺跡、試煉密室），分組名稱沿用同一個結構的譯名（掠奪者前哨站）。

二、指南針自帶的錯誤譯名：探險家指南針附的繁中有不少錯，例如把針葉林村莊寫成「大河村」、前面多了俄文字母的「Д雪村」、「礦井檯面」。有官方名稱的改用官方名稱，有怪字元的不再採用。

三、和地圖一致：結構名稱裡的生態域改用小地圖顯示的官方名稱，例如「熱帶草原村莊」改成「莽原村莊」。名稱裡還留著英文（例如「Alpine村莊」「Kousa 聖所」，同一個模組的方塊其實譯成「棶木」），或生態域叫法和地圖不同的，會列在「建議確認」，也會交給 AI 核對；AI 確認沒問題的之後不會再送。

四、Bakery 模組的「麵包店」結構之前被當成模組名稱而保留英文，現在會翻譯。

更新後請對整合包再按一次「一鍵完整翻譯並套用」，並勾選 AI 補翻與核對。已經存在的舊地圖路標名稱不會自動改，重新用指南針搜尋一次就會產生中文的新路標。
