這一版讓上一版卡住沒寫入的設定說明也能寫進遊戲，並讓報告更好找。

- 有些模組把同一句設定說明在程式裡寫了兩次（例如 L_Ender's Cataclysm 的「Range Cap」）。AI 分兩次翻時可能給出兩種說法，之前程式怕互相蓋掉就兩邊都不寫，首頁顯示「未套用 7」。現在會自動統一成最可信的一種說法再寫入；你自己確認過的說法優先，不會被改掉。
- 報告的搜尋框現在也能搜尋疑點文字。例如搜尋「語系鍵」，就能找到跟設定語系鍵有關、需要確認的句子。
- 已用一個 CurseForge 整合包的副本實際測過：設定說明 525 句全部寫入並回讀相符，未套用變成 0；模組檔沒有被修改，重跑不再寫入，還原後與原檔完全相同。

舊有設定、報告與備份可繼續沿用。更新後再按一次「一鍵完整翻譯並套用」。
