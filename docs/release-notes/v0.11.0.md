這一版修正遊戲裡還看得到的英文，並把開始頁的數字改成直接回答「遊戲裡還有沒有英文」。

- 修正 Explorer's Compass 這類模組名稱或說明還是英文：有些模組自己的繁中檔裡直接寫著英文，而遊戲把「模組資源」排在翻譯資源包上面，蓋掉了我們的翻譯。現在會自動把翻譯資源包排在模組資源之上。還沒更新前，可以在遊戲的資源包畫面把 MCTranslator-zh_tw 移到 Mod Resources 上面。
- AI 翻好卻被過嚴的檢查退回的句子現在會採用：顏色代碼在中文語序下重新出現、書本裡自動帶入的詞（例如靈氣）多用一次、參數順序因中文語序對調（程式會自動加上編號，遊戲會把值放對位置）。連結、按鍵、參數數量不同這類真正有問題的仍然會擋下。打開舊報告時會直接用新規則重新檢查，不必再花 AI 額度。
- 同一段文字並列英文和簡中的教學動畫說明（Ponderer，例如煉丹爐的說明），現在會加上繁中；英文沒寫完時以完整的簡中轉成台灣用語。只有確認過模組會讀繁中的格式才寫入。
- 開始頁改成兩個數字：中文化完成率與還缺中文。寫入後會回頭讀遊戲實際讀取的檔案確認；比例無條件捨去，只有全部都是中文才顯示 100%。進度區會寫「這次從多少提升到多少」。
- 報告新增「程式內文字（CurseForge 會換回）」分類，把寫在模組程式裡、CurseForge 開遊戲時會換回原版而無法保留翻譯的文字分開列出。

舊有設定、報告與備份可繼續沿用。更新後請再按一次「一鍵完整翻譯並套用」。
