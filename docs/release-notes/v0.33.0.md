這一版讓「已翻譯整合包」可以順便把翻譯者的伺服器加進遊戲裡。

一、分享者可以替整合包的翻譯卡片設定一個伺服器（名稱和位址）。其他玩家按「安裝整合包與翻譯」、「安裝翻譯」或「重新安裝」後，打開遊戲的「多人遊戲」，最上面就會出現這個伺服器，點兩下就能連線，不用自己輸入位址。

二、清單裡已經有同一個位址時不會重複加入；整合包原本自帶的伺服器都保留不動。加入的這一筆和翻譯一起備份，不想要時可在「備份與還原」移除。

三、位址是 26 開頭（Radmin VPN）或 25 開頭（Hamachi）時，卡片會提醒要先加入分享者的那個網路才連得上。網路名稱和密碼請向分享者索取，卡片上不會寫。伺服器要開著才進得去。

四、已經裝好翻譯的玩家，更新程式後在卡片按一次「重新安裝」，伺服器就會加進清單。
