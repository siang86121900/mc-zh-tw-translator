這一版修正部分整合包套用時被擋下的問題，並在有新的現成翻譯時提醒你。

修正

- 修正套用時出現「Duplicate deployment destination」而整批停止：整合包的 KubeJS 已有某個模組的語系檔、同時該模組又內嵌在其他模組裡時（例如 Tensura 的 manascore），兩邊的譯文現在會合併成同一個檔案寫入。
- 寫入時的錯誤訊息改成中文，並說明有沒有修改到檔案、下一步怎麼做。

套用時更清楚

- 從報告頁按「備份並套用譯文」後，開始頁會馬上顯示要套用到哪個整合包、共幾筆，以及目前在做什麼（整理譯文、確認遊戲已關閉、檢查模組檔等），不會再像卡住。
- 已套用一部分、還有譯文沒寫入的批次，報告標示改為「部分套用」。

現成翻譯

- 有新上架、你還沒看過的翻譯時，側欄會顯示「現成翻譯（N 個新）」，卡片標示「新」。
- 新上架的翻譯正好是你電腦上的整合包時，會跳出 Windows 通知。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
