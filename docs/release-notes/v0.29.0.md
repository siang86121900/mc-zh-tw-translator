這一版讓整合包資料包裡的 NPC 名稱、商店分類、系統訊息和書本也會翻成繁體中文。

一、NPC 與商店：寶可夢商店店員頭上的名字（例如 Poké Trader）和商店分類（例如 Cobble Balls、Healing Items）寫在整合包資料包的建築檔裡，遊戲照原樣顯示，之前一直是英文。現在程式會讀這些建築檔，連同告示牌、放在建築裡的書（例如寶可夢中心的圖鑑書）一起翻譯，只改文字，其他內容不動。RCT 訓練家的名稱也會翻譯。

二、系統訊息與書本：整合包用指令送出的聊天訊息（例如切換新地區時「請重新開啟世界」的提醒）、給玩家的攻略書與通關祝賀書、道館地圖的名稱，現在也會翻成繁體中文，顏色、粗體和可點擊的連結都保留。

三、請注意：建築檔只影響之後才生成的地方。已經在你世界裡出現過的店員和告示牌存在存檔裡，程式不修改存檔，所以會維持英文；新開的世界或還沒探索到的地方會是中文。CurseForge 會自動換回原版的模組（例如 CobbleDollars 商店畫面上的 Buy、Categories）無法保留修改，報告會列在「無法寫入」並寫明原因。

四、寶可夢名稱與轉換錯字：尼多后、焰后蜥、甜冷美后和仆刀將軍之前被誤當成簡體字，改成了錯的「尼多後」「僕刀將軍」，重跑時會改回正確名稱並列在「建議確認」。同時修正簡中轉繁體時同一類的錯字：音譯名稱裡的「託」改回「托」（洛托姆、薩拉托加），栗木、栗樹不再寫成「慄」，「熒光」改為台灣用的「螢光」，「夠讚」不再寫成「夠贊」。這些規則用五個真實整合包統計確認過，委託、戰慄、贊助等正確用法不會被改動。

五、防止漏掉：資料檔裡有英文句子、程式卻還不會讀的格式，現在也會在報告上方用紅字列出，不會默默略過。
