這一版修正有些模組整個沒被翻譯的問題，並讓「已翻譯整合包」頁說明記憶體怎麼設定。

- 有些模組自帶的簡中檔裡有打錯的表情符號（例如 TravelOptics），以前程式讀到就整個模組略過，連英文都沒掃到，報告只顯示一行英文錯誤。現在只略過打錯的那一句，其餘照常翻譯；這類問題也改用白話說明。
- 已翻譯整合包的卡片會顯示整合包作者建議的記憶體大小，按「怎麼調整記憶體」可看到在 CurseForge 調整的步驟。你的電腦記憶體分完後剩不多時會提醒。程式只讀取，不會修改 CurseForge 的設定。
- 同一個整合包有多個版本的翻譯時，改用整合包本身的版本判斷哪個最新，重新發布舊版翻譯不會再被當成最新版。
- 已翻譯整合包有 9 個以上時會出現搜尋框，可以用名稱或 Minecraft 版本搜尋。

舊有設定、報告與備份可繼續沿用。用過舊版翻譯的整合包建議重新按一次「一鍵完整翻譯並套用」，把先前被略過的模組補上。
