這一版讓「已翻譯整合包」的安裝進度更清楚。

一、按「安裝整合包與翻譯」後會開一個進度視窗，寫明現在是第 1 步（等 CurseForge 下載整合包）還是第 2 步（裝上翻譯）。很多玩家看到 CurseForge 顯示裝好了就開遊戲，其實翻譯還在裝，畫面因此是英文。現在 CurseForge 一裝好，進度視窗就會跳到最前面，並發出 Windows 通知提醒先不要開遊戲；看到「翻譯已安裝」的視窗才算完成。安裝翻譯、安裝或更新整包分享的整合包時，也會顯示同樣的進度視窗，工作列的圖示也會顯示進度。

二、安裝完成後，卡片會直接變成「重新安裝」，不用再按重新整理。從 CurseForge 裝好或刪掉整合包後回到本程式，卡片也會自動跟著改變。
