這一版可以把翻好的整合包直接分享給朋友，翻譯來源也改以最道地的台灣用詞排序。

現成翻譯（新頁面）

- 匯出翻譯補丁：把已套用的翻譯打包成一個小 zip，只含翻譯文字，不含任何模組檔，傳給朋友即可。
- 套用翻譯補丁：程式會自動找到你電腦上的 CurseForge 整合包（包含自訂位置），先備份原檔再套用，可在「備份與還原」復原。
- 整合包版本不同時，只套用和翻譯時完全相同的模組檔，其他的略過、不會覆蓋，並列出略過了哪些。
- 預留「可下載的翻譯」清單與「用 CurseForge 安裝整合包」按鈕，之後公開的現成翻譯會出現在這裡。
- 補丁含社群譯文，依 CC BY-NC-SA 4.0 須免費分享，補丁內附來源說明。

翻譯來源順序

- 改以最準確、最道地的台灣用詞排序：台灣翻譯組人工繁中（ModsTranslationPack、ParaTranslationPack）優先於模組自帶繁中與簡中轉繁。
- 參考庫的繁中必須和目前模組版本的英文相同才優先採用，版本不同的會標示待核對。
- 以 Tensura 為例，約 1 萬筆原本簡中轉繁或模組自帶的譯文，改用台灣翻譯組的人工繁中。

其他

- 套用時的模組檔完整性檢查改用 CurseForge 或 Minecraft 啟動器內建的 Java，電腦沒有另外安裝 Java 也能套用。

更新只替換程式本身，翻譯資料、備份與設定都會保留。
