這一版修正兩個會讓譯文變差的判斷錯誤。

- 判斷文字是不是簡體字時，之前會把台灣正常的字當成簡體，例如「吃」「背包」「游標」「了解」「秘密」「才」。被誤判的模組自帶繁中會被降低順位或重新轉換。現在只有真正的簡體字（例如「虚」「别」「恒」「云杉」「之后」）才會被認出來。
- 簡體轉繁體時常把「鐘」寫成姓氏的「鍾」，例如時間模組的「鐘石」變成「鍾石」、「獄髓鐘」變成「獄髓鍾」。現在會自動改正，模組自帶的繁中有同樣錯字也會改，改過的列在「建議確認」。「鍾愛」「鍾情」「情有獨鍾」這些正確用法不會被改。
