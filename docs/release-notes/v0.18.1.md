這一版修正上一版可能讓整合包無法啟動的問題，請盡快更新。

- 上一版會把自己加裝的模組裡寫死的文字翻譯後寫回模組。但有些模組會在遊戲啟動時修改其他模組的程式，而且要找到一句指定的英文原文才能改（例如 The Foll 裡的 RevelationFix 會找 GoetyRevelation 的一句設定說明）。那句被翻譯後找不到，遊戲就停在載入畫面。
- 現在掃描時會找出所有會被其他模組修改的程式，包含藏在模組裡的小模組，這些程式裡的文字一律不改，也不送 AI。上一版已經改過的，重新翻譯時會自動改回原文。
- 上一版產生的報告不知道這件事，所以用舊報告按「重試套用」時不會寫入模組程式裡的文字，請重新按一次「一鍵完整翻譯並套用」。
- 模組作者用來產生語系檔的工具程式（例如 ZhCnProvider）裡的文字不會出現在遊戲中，遊戲讀的是模組附的語系檔，那份已經另外翻好。這些文字改列在「無需翻譯」，不再混在待查裡。
- 「待查程式與設定」改名為「無法確定是否顯示」，說明這些文字為什麼沒有改：程式無法確定遊戲會不會顯示，也可能是拿來比對的名稱，改了可能讓模組出錯。

如果遊戲已經因為上一版無法啟動：打開「備份與還原」，從最新的一批開始往回還原，直到遊戲能正常啟動，再用這一版重新翻譯。舊有設定、報告與備份可繼續沿用。
