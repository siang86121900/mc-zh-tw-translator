這次讓已翻譯整合包分享出去時，設定檔和腳本裡翻成繁體的文字也會一起帶給安裝的人。

以前分享的翻譯只包含語系檔，像主畫面按鈕、整合包的歡迎說明、CraftTweaker 物品提示這類寫在設定檔或腳本裡的文字，安裝的人要自己再按一次一鍵翻譯才會變成繁體。現在這些文字也會放進翻譯裡，按「安裝翻譯」或「更新翻譯」就會一起套用。

為了安全，分享時不會放整份設定檔或腳本，只記下哪一句從簡體改成了繁體。安裝時你的檔案必須和翻譯者的原檔一模一樣才會修改，而且每一處只能改中文字，英文、數字和符號都不能變動，所以不可能夾帶任何程式。改完會再比對一次，必須和翻譯者的結果完全相同，也可以從備份與還原復原。

含有這類文字的翻譯需要這個版本以上的程式才能安裝，舊版程式會提示先更新。

另外修正使用 Sinytra Connector 的整合包（例如 Tensura）裡，Fabric 模組的翻譯在別人電腦上會被當成版本不同而略過的問題。Connector 會在每台電腦自己產生轉換檔，現在程式只認原本的模組檔。
