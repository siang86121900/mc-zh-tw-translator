修正安裝時缺少圖片元件的錯誤

修正 v0.38.0 的 Windows EXE 遺漏封面功能需要的圖片元件，導致安裝或更新整合包時顯示「No module named PIL」並停止的問題。這是程式打包問題，玩家不需安裝 Python 或其他元件；更新 APP 後再試原本的安裝或更新即可。

新版將圖片產生、圖片讀取與字型處理需要的元件納入 EXE。之後每次發布都會執行打包後的 EXE，實際產生封面、讀取自訂圖片，並用不含封面的舊格式壓縮檔在隔離資料夾完成安裝與封面登記；任一步失敗就停止發布。

隔離驗證不修改玩家真實的 CurseForge 紀錄或遊戲資料。此版只更新 APP，不重新上架整合包，也不變更雲端下載內容。已完成的翻譯、報告與備份保留；實際玩家端 CurseForge 卡片顯示仍需重新開啟確認。
