# 桌面介面與更新

視覺參考為使用者指定的 `siang86121900/ai-agent-team`，檢視版本 `0810c6fff5bee934306f131c327d7c2126932f86` 的 `DESIGN.md` 與 `projects/jira/templates/index.html`。本專案重新實作原生 Qt Widgets 介面，不打包該私人專案的程式、資料或登入資訊。

沿用 #278AFC 藍色、#F8F8F8 背景、白色卡片、細灰框線和 8px 圓角。18px 頁面標題、13px 區塊標題、14px 正文，52px 頂列與緊湊間距。字體透過 Qt QFont 選擇 Segoe UI／微軟正黑體，避免以不可靠的樣式字體清單造成回退；亮暗主題、小視窗與高 DPI 都需渲染檢查。小視窗使用捲動頁面，明確樣式的 QListView 取代原生下拉彈層。

五個頁面：開始翻譯、翻譯報告、備份與還原、程式更新、AI 帳號與模型。工作以背景執行緒處理，UI 顯示實際進度。掃描、登入與 AI 補翻可取消，套用和更新禁止中途關閉。大報告用搜尋、分類與每頁 100 筆避免載入全部列造成畫面停頓。

啟動時在獨立背景工作查版本（可關閉），側欄與頂端提示新版本。檢查不下載 EXE，安裝前另有確認。下載驗證 SHA-256、檔案大小與 MZ 標頭；下載版本以輔助模式等待舊程序退出後替換 EXE，保留前版，重啟原路徑。無法取得的更新不得顯示成「已是最新」。

主流程只有一鍵翻譯。開始掃描就建立報告，掃描後先提供原文預覽；來源比對與 AI 分批保存。UI 只接收最近 200 筆的不可變進度快照，結束才載入完整報告；表格每頁 100 筆。套用失敗或偵測到遊戲時回傳持久化狀態，不能只拋例外丟失 UI 結果。啟動時自動載入最近報告；提供重試套用並重新檢查來源雜湊與程序。

可選用官方 Codex App Server 的 ChatGPT 登入；只提供原方案額度模式，拒絕 API key、企業點數方案、額外點數、未知額度及低於安全餘額的請求。每次登入和補翻前明示會消耗原本 Codex 額度。模型選單依官方 model/list 動態載入，沒有硬編模型或免費／品質保證。

官方元件可在程式中經同意下載並驗 SHA-256。它擁有本程式獨立的登入目錄，子程序環境只保留必要系統變數，不繼承 API key 或代理端點；程式不讀 token。每次小批次重新檢查帳號／額度，禁用 shell、網路搜尋與代理擴充，拒絕工具要求。回應以嚴格 JSON 檢查筆數、id、參數、數值及換行，批次完成即寫入本機報告。AI 候選不能冒充人工完成，也不直接操作遊戲檔案。

仍未涵蓋的腳本、設定和 class 只作待查候選，不自動修改機器欄位。Gemini／Claude 尚未接入。沒有供應商端消費鎖，額度快照也可能因其他裝置同步使用而改變，因此不宣稱平台層級的零消費保證；本程式自身不提供 API、加購、付費降級或兌換額度功能。
